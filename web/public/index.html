Ein schneller, aufgeräumter Browser für Windows.

Caravel basiert auf Chromium und bringt Werbeblocker, kostenloses VPN, eine KI-Seitenleiste und verschlüsselten Sync gleich mit – ohne Konto und ohne Tracking.

Für Windows herunterladen Windows 10 und 11, 64 Bit

Funktionen

Alles, was man von einem modernen Browser erwartet, und einiges, das man sonst erst nachrüsten muss.

Werbeblocker

Mit den Filterlisten von uBlock Origin, inklusive YouTube-Werbung. Twitch-Werbepausen werden übersprungen.

Kostenloses VPN

Tor mit Länderwahl oder eigene Server über WireGuard, SOCKS5 und HTTP – gilt nur für den Browser.

KI-Seitenleiste

Claude oder ChatGPT neben jeder Seite. Seiten zusammenfassen, Auswahl erklären oder übersetzen. Komplett abschaltbar.

Chrome-Erweiterungen

Erweiterungen direkt aus dem Chrome Web Store installieren.

Spaces und Split View

Tabs nach Themen trennen, zwei Seiten nebeneinander öffnen, Links in einer Vorschau ansehen.

Chromecast

Cast-Knöpfe von Webseiten, Tab oder Bildschirm spiegeln und lokale Dateien abspielen.

Leseansicht und Leseliste

Artikel ohne Ablenkung lesen, vorlesen lassen oder samt Bildern für offline speichern.

Passwort-Manager

Mit Windows verschlüsselt, Import und Export als CSV, Übernahme aus Chrome, Edge und Brave.

Automatische Updates

Neue Versionen laden im Hintergrund und werden beim Beenden installiert.

Sync, den nur du lesen kannst

Favoriten, Seiten-Notizen, Boosts, Zeitkapseln und Passwörter bleiben auf all deinen PCs gleich. Caravel verschlüsselt alles auf dem Gerät, bevor es hochgeladen wird.

  • Ende-zu-Ende verschlüsselt mit AES-256-GCM. Der Server speichert nur Daten, die er selbst nicht lesen kann.
  • Kein Konto, keine E-Mail. Ein Sync-Code verbindet deine Geräte – er verlässt sie nie.
  • Oder ganz ohne Server: über einen Ordner in OneDrive, Dropbox oder auf einem Netzlaufwerk.
  • Einrichten unter Einstellungen › Sync.
